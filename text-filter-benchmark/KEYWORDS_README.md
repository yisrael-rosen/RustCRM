# Multi-Keyword Text Filter - Zig Implementation

מנוע סינון טקסט מתקדם עם 50 מילות מפתח בעברית

## תיאור

מנוע סינון טקסט חזק המסנן קבצים גדולים לפי 50 מילות מפתח בעברית. המערכת כוללת שתי גרסאות:

1. **גרסה בסיסית** - עיבוד סינכרוני רגיל
2. **גרסה מקבילית** - עיבוד מקבילי עם ניצול מלא של כל ליבות המעבד

## מילות המפתח (50 מילים)

המנוע מחפש 50 מילות מפתח בעברית המחולקות ל-5 קטגוריות:

### קטגוריה 1: תקשורת ומידע
שלום, הודעה, מידע, עדכון, התראה, דיווח, פרטים, תיאור, הסבר, תוכן

### קטגוריה 2: פעולות עסקיות
רכישה, מכירה, עסקה, הזמנה, תשלום, חשבונית, הצעה, חוזה, הסכם, דיל

### קטגוריה 3: סטטוס ומצב
מאושר, ממתין, בטיפול, הושלם, בוטל, נדחה, פעיל, סגור, פתוח, חדש

### קטגוריה 4: לקוחות וקשרים
לקוח, חברה, איש קשר, ספק, שותף, צוות, מנהל, משתמש, משקיע, יועץ

### קטגוריה 5: משימות ופעילות
משימה, פגישה, שיחה, אימייל, פעילות, מעקב, תזכורת, יומן, לוח, תכנון

## בנייה

```bash
./build_keywords.sh
```

הסקריפט יבנה את שתי הגרסאות עם אופטימיזציות מלאות.

## שימוש

### גרסה בסיסית
```bash
./zig/filter_keywords <input_file>
```

### גרסה מקבילית
```bash
./optimized/zig/filter_keywords_optimized <input_file>
```

## דוגמת שימוש

```bash
# יצירת קובץ בדיקה גדול
for i in {1..10000}; do cat data/test_hebrew.txt; done > data/test_hebrew_large.txt

# הרצת הגרסה הבסיסית
./zig/filter_keywords data/test_hebrew_large.txt

# הרצת הגרסה המקבילית
./optimized/zig/filter_keywords_optimized data/test_hebrew_large.txt
```

## ביצועים

בדיקת ביצועים על קובץ של 25MB עם ~520,000 שורות:

| גרסה | זמן עיבוד | קווים לשנייה | קצב העברה |
|------|------------|---------------|-----------|
| בסיסית | 1165ms | 446 קווים/ms | ~21 MB/s |
| מקבילית | 204ms | 2549 קווים/ms | ~122 MB/s |
| **שיפור** | **5.7x** | **5.7x** | **5.8x** |

### תוצאות מפורטות

**גרסה בסיסית:**
- זמן עיבוד: 1165ms
- שורות מתאימות: 470,000 מתוך 520,001
- 48 מילות מפתח נמצאו (מתוך 50)
- סה"כ התאמות: 1,330,000

**גרסה מקבילית:**
- זמן עיבוד: 204ms
- שורות מתאימות: 470,000 מתוך 520,008
- 48 מילות מפתח נמצאו (מתוך 50)
- סה"כ התאמות: 1,330,000
- מעבדים: 8 threads
- קצב עיבוד: 2,549 קווים למילישנייה
- throughput: 122.29 MB/s

## פרטים טכניים

### אלגוריתם החיפוש

1. **גרסה בסיסית**:
   - קריאת הקובץ לזיכרון
   - חיפוש סריקתי (sequential scan) בכל שורה
   - בדיקת כל 50 מילות המפתח בכל שורה
   - שמירת סטטיסטיקות על התאמות

2. **גרסה מקבילית**:
   - קריאת הקובץ לזיכרון
   - חלוקת הנתונים ל-N חלקים (לפי מספר ליבות המעבד)
   - עיבוד מקביל של כל חלק ב-thread נפרד
   - איחוד התוצאות מכל ה-threads
   - חישוב סטטיסטיקות מפורטות

### אופטימיזציות

- **String Search**: שימוש ב-`std.mem.indexOf` המהיר של Zig
- **Memory Management**: קריאת הקובץ פעם אחת לזיכרון
- **Parallel Processing**: ניצול מלא של כל ליבות המעבד (עד 8)
- **Release Optimization**: קומפילציה עם `-O ReleaseFast`

## מקרי שימוש

1. **סינון תוכן CRM**: זיהוי הודעות עם מילות מפתח עסקיות
2. **ניתוח לוגים**: סינון אירועים לפי מילות מפתח
