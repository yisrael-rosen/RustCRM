# תוצאות בדיקה על דפי ויקיפדיה גדולים

## סקירה

בדיקת מנוע סינון ה-HTML על דפי ויקיפדיה גדולים במיוחד (1-3.8 MB) - **הדפים הגדולים ביותר בויקיפדיה העברית**.

## קבצי הבדיקה

1. **הומופוביה ברחבי העולם** - 3.8 MB (הדף הגדול ביותר בויקיפדיה העברית!) 🏆
2. **מלחמת חרבות ברזל** - 2.3 MB (הדף השני בגודלו)
3. **יוטיוב** - 1.3 MB (דף מקיף על פלטפורמת הווידאו)

## מקרי שימוש מתקדמים

### 1. עיבוד המוני של ארכיון ויקיפדיה

```bash
# עיבוד 1000 דפי ויקיפדיה (~1.5 GB)

    ./optimized/zig/filter_html_keywords_optimized "$file" >> results.txt
done

# זמן משוער: ~40 שניות (במקום 20-30 דקות ב-Python!)
```

### 2. ניטור חדשות בזמן אמת

```bash
# סריקת עדכוני חדשות כל דקה
while true; do
    wget -q -O /tmp/news.html "https://news.site/latest"
    ./optimized/zig/filter_html_keywords_optimized /tmp/news.html
    sleep 60
done
```
